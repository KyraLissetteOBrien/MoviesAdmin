# MoviesAdmin

What its using: C# Razor through Visual Studio to integrate C# into HTML.
What its for: The backend system for a movie website where critics can go to review movies, and administrators can go to manage movie data, using BootStrap CSS. 

Tools & Technologies: 
https://getbootstrap.com/ - styling | ASP.NET Core MVC - web framework | Entity Framework Core - ORM / database access | SQL Server (Docker) - database, run in a local container | Azurite (Docker) - local Azure Blob Storage emulator for poster images | Auth0 - authentication, user accounts and role management | Azure - cloud hosting for the app and database 

IDE: 
https://visualstudio.microsoft.com/
